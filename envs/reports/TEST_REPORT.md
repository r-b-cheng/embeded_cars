## 2. 无噪声数值误差

| 项目 | 实际最大绝对误差 | 通过标准 |
|---|---:|---:|
| 有效测距 | 2.968292e-12 m | ≤ 1e-9 m |
| 位置 | 4.619382e-14 m | < 1e-9 m |
| 航向 | 5.706546e-14 rad | < 1e-9 rad |
| 陀螺 Z 轴角速度 | 5.551115e-17 rad/s | < 1e-10 rad/s |
| IMU 比力分量 | 8.881784e-16 m/s² | < 1e-9 m/s² |
| 编码器累计/增量计数 | 0 tick | 整数完全相等 |

测距检查包括 121,058 次有效读数、8,878 次无回波和 64 次近场盲区。
无效观测必须返回正确状态和 `None`，不会把最大量程当成障碍位置。

**上述误差是两个数学实现之间的数值差异，不能解读成真实传感器达到这个精度。**

## 3. 基准独立性

生产内核使用 NumPy 的射线/线段求交和扇区最近点计算。
测试通过原始地图 JSON 独立构建 Shapely/GEOS 几何，使用几何求交和点到几何距离作为基准。
没有调用被测测距函数来生成期望值，也没有直接复用生产内核的边数组。

运动基准采用复平面指数表达式，被测实现采用实数形式的圆弧积分。
IMU 期望值来自已知轮命令、步长与安装位置的公式；编码器期望值独立累计轮转角并量化。

复现完整验收：

```bash
cd envs
python -m pip install -e ".[visual,test]"
python -m coverage run -m pytest -q --junitxml=reports/junit.xml
python -m coverage report
```
