# 数学模型、单位与验收含义

## 坐标和运动

世界坐标 X 向右、Y 向上，yaw 从 X 轴起算、逆时针为正，单位弧度。
车身坐标 X 向前、Y 向左、Z 向上。`mount=[x,y,yaw]` 相对车体中心。
圆形车体半径决定碰撞外形；轮距单独决定差速转动。

PWM 是 [-100,100] 的有符号占空比。每轮目标线速度由以下量相乘：

`目标轮速 = PWM / 100 × 标称满速 × 该轮增益`。

`max_wheel_speed_m_s` 在此模型中是增益为 1 时的标称满速，增益大于 1 时实际模拟轮速可以稍高。

电机时间常数为零时立即达到目标轮速。大于零时，使用一阶响应更新：

`新轮速 = 目标轮速 + (旧轮速 - 目标轮速) × exp(-dt / tau)`。

`dt` 是物理步长，`tau` 是电机时间常数。这个式子是恒定目标下一阶微分方程的解析速度更新。
每个物理步内将新的轮速保持常数；因此含电机滞后时，位移仍是离散时间近似。

地面有效轮速为 `轴线速度 × (1 - slip)`。左右地面轮速分别为 `vL,vR`，轮距为 `b`：

- 车体前向速度 `v = (vL + vR)/2`：中心位于两轮中间。
- 角速度 `omega = (vR - vL)/b`：两轮走过的弧长差等于转角乘以轮距。

每个恒速时间步按圆弧解析积分；角速度趋近零时用 sinc 连续极限处理。验收的独立实现用复平面指数积分，两者不共享函数。

碰撞时整个该步的车身位姿保持原值，速度设为零；轴转动仍累计。扫掠检测检查整个运动路径，额外用圆弧相对弦的最大偏差扩大检测半径。这个检测偏保守，不解析接触力和滑动。

## 测距

单束红外和 LiDAR 求射线与地图边界、障碍边的最近正向交点。
地图边界始终作为墙存在，不允许无边界世界。

超声波采用一个有限角度扇区，返回其中最近障碍边的欧氏距离。
对每条线段，扇区内距离最小点只能来自：端点、垂直投影点、或与扇区两条边界射线的交点。
代码枚举这些候选并求最小值。因此不存在“只取几根稀疏射线而漏掉中间窄障碍”的离散角度误差。

独立校验将地图交给 GEOS，用三角形半平面区域截取声束方向内的几何，再求距离并限制量程。测试没有调用生产射线函数，也没有直接把生产几何边数组作为基准输入。

这个扇区模型不表达声压、反射方向、材料吸收、发射/接收换能器间距、多径或高度遮挡。
有限扇区声呐只返回距离，没有反射点的精确角度。将返回值直接放在中心射线上建图，仍然是定位算法自身的近似。

若真实几何距离小于最小量程，返回 `below_min`；超过最大量程，返回 `no_echo`。
在有效回波上独立施加丢测概率和高斯距离噪声；噪声后的有效读数截断到配置量程内。
`echo_time_s = 2 × distance_m / sound_speed_m_s`，其中 2 表示声波往返。

## IMU

模型只允许平面运动。六轴数据形式中，X/Y 角速度固定为 0，Z 轴角速度来自车体转动；不返回真实 yaw。

车体中心的平面加速度分量：

`ax = (新前向速度 - 旧前向速度)/dt`，
`ay = 前向速度 × 角速度`。

第一项描述速度大小的变化，第二项描述转弯引起的向心加速度。
传感器在车体上的位置为 `(rx,ry)`，角加速度为 `alpha`：

`ax_sensor = ax - alpha × ry - omega² × rx`，
`ay_sensor = ay + alpha × rx - omega² × ry`。

附加项分别来自切向转动加速度和向心加速度。最后把向量旋转到传感器自身轴系。
Z 轴输出为 `+g`，它是支撑力对应的比力；水平静止加速度计不会输出三轴全零。

Z 轴陀螺可以添加恒定零偏、高斯噪声和零偏随机游走。游走每次采样的标准差是配置系数乘以 `sqrt(采样间隔)`。
加速度计支持独立各轴高斯噪声。碰撞、PWM 突变产生的离散加速度不用于模拟真实冲击波形。

## 编码器

编码器记录电机轴转角，而不是地面实际位移，因此打滑、顶墙时计数仍可能增长。

`连续计数 = 累计轮转角 / (2π) × 每转总计数`。

输出为最接近的有符号整数，恰好半格时远离零舍入；增量为相邻采样的累计计数差。
`ticks_per_rev` 必须填减速比和 AB 相解码倍频都换算后的“车轮一转总计数”。
每次 reset 将计数原点清零；读取样本不会再次消费增量。

## 精度解释

无噪声验收比较“数学模型输出”与“独立基准输出”。距离/位姿容差设为 1e-9 m，这只衡量软件数值一致性。
真实硬件误差还包括传感器安装、反射、舵机回差、电机模型、轮径和地面变化，必须另外标定。

增加噪声的测试检查均值、标准差、丢测比例与固定种子回放，不要求单个随机样本等于无噪声真值。

随机流由 SHA-256(全局种子、实例名) 分离，不使用全局 numpy.random 状态。日志记录采样时刻、到达时刻和序号；算法必须根据时间戳处理旧观测。
