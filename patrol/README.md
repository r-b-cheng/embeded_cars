# 教学楼巡逻车

Android 负责遥控、途经点和地图。TM4C123G 采集左右轮独立的 LM393 脉冲、GY-521 六轴原始值和三向声呐，在车上执行定距、定角、避障和断联停车。手机显示双轮 RPM、车速、累计路程和相对航向，在「遥测」内可查看完整传感器与诊断字段。

## 接线和首次使用

1. 对照[逐针表和校准步骤](WIRING.md)或[整车接线图](wiring.png)安装模块。先断开电机支路，复测 IN1–IN4 在停车后全部为低。11 月 24 日的旧固件曾出现停车后两路仍高，新版改了 PWM 切换顺序，仍需在车上复测。[旧台架记录](bench/2026-11-24.md)
2. **手机热点方案**使用本地生成的 `build/personal/patrol.bin`。备份需要保留的旧程序后，烧录到 TM4C Flash 地址 **0x00000000** 并校验，复位时将小车保持静止。手机开启相应名称和口令的 **2.4 GHz、WPA2 个人热点**。ESP-01S 上电后自动加入，读取 DHCP 网关并主动连接手机。手机安装[小车巡逻 APK](dist/patrol-debug.apk)，点「连接 → 等待小车 → 新测区」，无需填写 IP。关闭控制页会断开会话。要重新连接，再点「等待小车」。
3. **公开演示固件** [dist/patrol.bin](dist/patrol.bin) 建立 `Patrol-Car` 热点，演示密码 `SurveyCar01`。让手机加入该 Wi-Fi，点「连接 → 输入 IP」，填 `192.168.4.1`。在专用固件模式也可手填手机热点分配给 ESP 的 IP，端口均为 TCP 7070。
4. IMU 就绪后分别手转左右轮核对各自脉冲与里程，左转车身核对正角。架空测试按住前进、松手、左右转和停车。车端需要三个方向都有有效回波。校准实际轮周、每圈脉冲、轮距和转向后，再在平地验证 20 cm、50 cm、左右 90° 和实际滑行距离。
5. 「持续前进」点一次开始，「停车」结束。「定距前进」输入 1–1000 cm，「定角转弯」输入 −360 至 +360°，正数左转、负数右转。任务目标在车上判定。手机切后台、失联、SW1、障碍或持续缺失回波会停止手机手动任务。车端每次运动指令有效期为 650 ms。持续驱动约 1 秒仍无码盘反馈或 IMU 失效时，车端收回驱动，需停车后重新操作。

## 日志

车端在片内 Flash 最后两个 1 KiB 页轮换记录启动、断连、续约超时、SW1、运动反馈异常、遇障停车及停车输出电平异常。每条 16 字节，带序号、上电毫秒和 CRC。跨页时回收最旧一页，最多保留 128 条。上电恢复有效记录，遇障事件限频为每 30 秒一次。全片擦除会清空记录。需要保留日志时先连接手机回传并导出，或烧录时选择仅擦写程序所占页。

App 0.3 会保存在线期间全部请求、收到的遥测、任务决定、状态和异常，点「导出日志」得到 UTF-8 TSV，同时保留此前版本的日志。离线时，车端保留关键 Flash 事件和最近 128 条 RAM 运行事件。连接后，每帧最多补传两条（Flash、RAM 各一条）。六轴在车端约每 10 ms 更新一次，手机按约 100 ms 加往返耗时记录最新快照。断线期间的逐帧传感器数据无法从关键事件还原。

UART 收发和手机日志写入各有缓冲。手机磁盘阻塞时，2048 行队列用尽后继续控制，界面显示缺失数，恢复写入时在 TSV 中标记 `#GAP`。日志文件会随记录时间增长，导出使用系统文件选择器并结束当前前台控制会话。车端日志和诊断字段见[协议](API.md)。

## 智能模式

先连车并确认 IMU 就绪，点「智能」填写任务。按「停车」、切换手动操作、退出前台或断线都会撤销智能控制，迟到的模型回复会失效。车端继续执行声呐净空、轮速反馈和指令续约检查。

- **手机 API** 填写完整 HTTPS Chat Completions 接口 URL、模型名和 API Key。任务、最新遥测、上一步结果及车位周围 11×11 格地图发给所填服务。Key 仅保留在本次会话内。手机需能访问该服务。请求期间车辆停车，遥测和续约独立运行。每步完成后重新观测，每轮最多 32 步。联调本地测试服务可使用 ADB reverse 和 `http://127.0.0.1:端口/路径`。
- **电脑 ADB** 在手机选择「电脑 ADB」。打开 USB 调试并授权电脑，在本目录运行下面的命令。Codex 先读[系统提示词](android/assets/system-prompt.txt)，再取快照，根据任务返回单步动作。取一次新快照会替换旧票据；行驶期间仍可读取遥测。点击手机停车或执行 stop 会结束会话。
- **动作** 前进 10–300 mm，原地转向 ±1–90°，等待，或结束。正角左转。手机校验票据、范围、位姿变化、最新回波和停车状态；每次决策及原因写入运行日志。

```sh
python3 tools/pilot_adb.py snapshot
python3 tools/pilot_adb.py decide --ticket "粘贴快照中的票据" --action forward --value 100 --reason "向前采样一格前的空闲区"
python3 tools/pilot_adb.py stop
```

## 扫描、避障与参照物定位

- TM4C 使用四路 20 kHz PWM 控制 L298N。独立宽定时器在 PC7 输出 50 Hz。舵机按中、左、中、右循环，分别使用 1500、1900、1500、1100 µs。每次转位等待 140 ms 再触发 HC-SR04，GPIO 双边沿中断记录 Echo，30 ms 超时。正前方每约 0.28–0.34 秒重测，两侧每约 0.56–0.68 秒重测。协议同时传回采样时的位姿，可在低速移动中扫描。
- 前方小于 40 cm 时车端将前进指令对应的轮速置零，手机重新规划。侧方较近时车端降低一侧占空比以轻微偏转。原地转向也受前方、侧面净空约束。测距失效、样本过旧或转向后朝向差太大时收回驱动。停车距离还受安装位置、实车速度与轮胎滑行影响。
- 手机用 **201 × 201 格、每格 20 cm** 的局部占据地图。测距射线穿过处累积空闲证据，终点累积障碍证据；规划时将障碍向周围扩大一格，使用四邻接最短路径。空间能覆盖约 40 × 40 m，长条楼层仍可能越界。
- 手机先按车端的编码器和陀螺仪位姿预测。收到一组新的三向测距，且行进约 18 cm 或转向约 18° 后，将回波终点和已有地图中连续、反复观测到的墙段匹配。单墙只调整墙面法线方向的位移，两个独立方向的墙段可修正平面位移。每次最多平移 10 cm，随后才写入该批回波。界面显示最近的“轮速推算 / 超声墙面校正 / 超声双向校正”。实车航向来自陀螺仪 Z 轴积分；相似走廊和移动家具可能造成错误关联。
- 首次实车标定：在已知距离和角度测左右声束的实际方位，填写 `firmware/control.c` 的 `bearing`。量有效轮周、每圈脉冲、轮距，调整 `firmware/calibration.h`。测出最大滑行停车距离后再设置净空阈值。仿真中的速度、车宽和车身圆形轮廓都是假设值。测量以车身中心近似声束原点，探头安装偏移会影响近场地图。

## 没有开发板时

在本目录运行。C 编译器、Python 3 和 JDK 可运行测试；Android 构建另外需要 SDK Platform 35 和 Build Tools 35.0.0。车端使用 Arm GNU Toolchain（含 newlib-nano）及 TI TivaWare 2.2.0.295。

```sh
make test
make renode-test
make TIVAWARE=/path/to/TivaWare_C_Series-2.2.0.295
./android/build.sh
make sim
python3 tests/simulator.py --bind 0.0.0.0
```

手机与电脑连同一个 Wi-Fi，把连接地址改为电脑局域网 IP（TCP 7070）。Android 模拟器填写 `10.0.2.2`。仅在电脑本机试验时，模拟器服务默认监听 `127.0.0.1`。应用和真车、模拟车共用[指令 API](API.md)。

## 离线验证与现场验收

双轮版 0.3 的 Renode 堵塞测试、日志压力测试和手机智能控制验证见[11 月 27 日测试记录](bench/2026-11-27.md)。

同日在 PLQ110 真机运行 0.2 版 App，使用 ADB 转发把电脑模拟车接入手机的 7071 监听端口。输入 10 cm 后，模拟码盘累计 102 mm 并报告完成；再左转 90°，相对航向从 1° 到 91°。持续前进遇模拟障碍停车。手机导出 900 帧 TSV，扩展帧字段数和请求序号逐条匹配。以下路线和探索数据来自兼容模式仿真。实车热点、Flash 写入及掉电恢复、停车输出及传感器精度待上车验证。

| 已执行的离线验证 | 观察结果 |
|---|---|
| 车端交叉编译、APK 构建签名、Android 模拟器连接 PC 模拟车 | 固件可链接，APK 可安装，能读取三向遥测、点选目标并收到路线完成状态 |
| 0.8 m 直线路线，估计轮速与仿真地面轮速有偏差 | 模拟车停在约 (0.68 m, 0.02 m)，坐标以模拟地面真值计算 |
| 1.6 m 目标，直线路径中放置宽 0.4 m 的障碍 | 小车绕行并停车，地面真值约 (1.61 m, −0.13 m)，仿真半径 10 cm 的车身接触计数为 0 |
| 12 × 10 m 场景的自主探索 | 自动选择探索目标，推进约 1.9 m 后因持续缺失回波而暂停；未覆盖整层 |
| 合成单墙、双墙；通信和测距故障 | 测试覆盖单墙法向修正、双向平移校正、失联、SW1、过期与缺失回波、转向后旧样本、AT 帧分包与断连 |

教学楼验收请分别记录已覆盖面积、每平方米用时、返回起点的漂移、最小墙距及漏检物。细椅腿、斜面、吸声物和探头高度以外的物体都是单超声波的盲区；在大于有效量程的开阔处，回波缺失会触发停车。完成整层地图、复访同一地点和无人巡视仍需现场数据、可靠里程反馈和补盲验证。建议先在有人看护的单间验证，再扩到一段走廊。
