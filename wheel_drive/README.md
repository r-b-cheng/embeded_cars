# wheel_drive — TM4C123G + L298N 双轮驱动程序

基于 [`../library`](../library) 的 `clib_motor`，给左右轮各一个 **有符号速度 −100~100**，
由库把动作映射成 L298N `IN1~IN4` 的四路互补 PWM。库代码一行没改，只补了 TM4C 的 port 层。

---

## 1. 文件清单

| 文件 | 作用 |
|---|---|
| `wheel.h` / `wheel.c` | 双轮驱动 API：`Wheel_Set(left, right)` / `Wheel_Stop()` / `Wheel_Brake()`。**芯片无关** |
| `board_tm4c123g.c` / `.h` | 唯一和芯片有关的文件：80MHz 时钟、4 路 20kHz PWM、SysTick 时基、UART0 调试口，`clib_port_t` 实现 |
| `main.c` | 演示：前进 → 后退 → 左右转 → 原地旋转 → 停，循环播放，串口打印动作 |
| `test_wheel.c` / `Makefile` | PC 端逻辑自测，**不需要开发板** |
| `README.md` | 本文（接线 + 编译 + 验收） |

## 2. 接线

### 2.1 先认清供电模块（照片里这块）

板子右下角丝印「多路电源」。从照片能读到的信息：

| 位置 | 是什么 |
|---|---|
| 右上 **黑色 DC 圆孔座** + **红色 2P 螺丝端子** | 电池输入（两个入口一般并联，任选其一）。照片里 DC 座已插着一根黑色电源线 |
| 旁边 **蓝色方块** | 总电源开关 / 按键 |
| 左侧 **黄色排针**：`可调电压` / `VADJ` | 可调输出，由板上蓝色电位器 `VR1` 调，LM2596 降压，**电流较大**，适合带电机 |
| 左侧 **红色排针**：`5V电压` | 固定 5V，LM2596，**电流较大**。照片里那对红黑线正插在这里（原来给红色 STM32 板供电） |
| 左侧 **蓝色排针**：`3V3电压` | 3.3V，LDO，**电流小**，只能给逻辑电路，别带电机 |
| 每排排针 | 是若干组 `V+ / G` 并联，随便挑一组用即可；**三排的 GND 是同一个地** |

> ⚠️ 照片分辨率有限，红色 2P 端子与蓝开关的丝印看不清。上电前用万用表**蜂鸣档**确认一下：
> DC 座中心针 ↔ 红端子 `+` 是否导通；DC 座外壳 ↔ 三色排针的 `G` 是否导通。
> 下面按「DC 座 / 红端子 = 输入，三色排针 = 输出」这个通用布局来讲。

> ⚠️ **接 L298N 之前必做**：万用表直流档量 `VADJ` 对 `GND`，旋 `VR1` 调到 **7~9V** 再接线。
> LM2596 是**降压**，输出一定低于电池电压；若电池是 2S 7.4V，`VADJ` 最多约 6V，这时改用下面的 **方案 B**。

### 2.2 方案 A（推荐）：供电模块直接给 L298N 供电

| 从 | 到 | 说明 |
|---|---|---|
| 电池组 `+ / −` | 供电模块 DC 座（或红 2P 端子） | 认清正负极 |
| 供电模块 `VADJ`（黄排，已调到 7~9V） | L298N **`+12V` / `VMS`** | 电机电源 |
| 供电模块 `GND`（黄排 `G`） | L298N **`GND`** | 大电流回路 |
| 供电模块 `GND` | TM4C123G **`GND`** | ★ **必须共地**，否则 IN 信号没有参考点、轮子会乱转 |
| L298N `OUT1` / `OUT2` | 左电机两根线 | 方向反了就对调这两根 |
| L298N `OUT3` / `OUT4` | 右电机两根线 | 同上 |
| TM4C123G **PB6** | L298N `IN1` | 左轮正转 PWM |
| TM4C123G **PB7** | L298N `IN2` | 左轮反转 PWM |
| TM4C123G **PB4** | L298N `IN3` | 右轮正转 PWM |
| TM4C123G **PB5** | L298N `IN4` | 右轮反转 PWM |
| TM4C123G USB | PC | 板子供电 + 115200 虚拟串口；**不要**再从 L298N 取 5V |

```
  电池 7.4~12V
       │
  ┌────▼─────────────────────┐
  │ 多路电源模块               │   DC 座/红 2P = 输入，蓝方块 = 开关
  └────┬──────────────┬──────┘
   VADJ(黄,7~9V)   GND(任意排 G)
       │              │
       │         ┌────┴─────────────────────────┐
       │         │  ★ GND 总线：模块 / L298N /  │
       │         │    LaunchPad 三者必须连一起   │
       │         └────┬────────────────────┬────┘
       ▼              ▼                    ▼
  ┌────────────────────────┐        ┌──────────────────────┐
  │ L298N                  │        │ TM4C123G LaunchPad   │
  │  +12V   GND   +5V(空)  │        │  USB → PC（供电/串口）│
  │  IN1 ← PB6             │        │  PB6 PB7 PB4 PB5     │
  │  IN2 ← PB7             │        │        ↓ 4 根信号线  │
  │  IN3 ← PB4             │        │  GND ─→ 共地          │
  │  IN4 ← PB5             │        └──────────────────────┘
  │  ENA / ENB 跳线帽：插着 │
  │  5V_EN 跳线帽：插着     │
  │  OUT1/OUT2 → 左电机     │
  │  OUT3/OUT4 → 右电机     │
  └────────────────────────┘
```

**L298N 上两个跳线帽怎么处理（最容易接错的地方）**

- `ENA` / `ENB` 跳线帽 **保持插上**。本程序是四路 PWM 直接打在 `IN1~IN4` 上调速，
  不靠使能脚；拔掉电机根本不转。
- `5V_EN`（有的板叫「5V 使能」）**保持插上**，此时板上 78M05 从 `+12V` 自己产生逻辑 5V，
  `+5V` 端子是**输出**。所以外部**不要**再往 `+5V` 端子送电，两个 5V 源会打架。
- 只有当 `VADJ` 做不到 ≥7V（78M05 稳不住）时，才**拔掉** `5V_EN`，改从供电模块**红色 5V 排**
  引一根 5V 到 L298N `+5V`。**两种只能选一种，绝不能同时。**

### 2.3 方案 B：电池直供电机（电压不够 / 电流不够时用）

电池正极并一根粗线**直接**到 L298N `+12V`，供电模块只负责逻辑（5V 排可留给开发板），
**GND 仍然三处全连**。出现以下现象就换这个方案：一加速就掉压、LaunchPad 重启、板上的灯闪。
原因：LM2596 约 2A 额定，两个 TT 电机堵转可能超额；且降压最多输出 `电池电压 − 1.5V`。

### 2.4 想脱离 USB 让小车自己跑

供电模块**红色 5V 排** → LaunchPad 上标 `VBUS` / `+5V` 的电源脚（**不是 `3V3` 脚**），同时共地。
注意别和 USB 同时供电，会往 PC 倒灌。蓝色 3V3 排本例程用不上。

### 2.5 电平与安全清单

- TM4C123 的 GPIO 输出高是 **3.3V**；L298 的 `VIH(min) = 2.3V`，能可靠识别，
  且 IN 脚是**输入**，不会把 5V 灌回 MCU，所以不需要电平转换。
  若实测某一路不动作，再加 74HCT245 / 电平转换模块。
- **绝对不要**把 L298N `+5V` 或供电模块的 5V 接到任何 TM4C GPIO（不是 5V 容忍输出）。
- 上电顺序：先接好所有 **GND** → 再接控制线 → 最后上电池。**先把车轮架空**再上电。
- L298N 板自带续流二极管，电机端不用外加。

## 3. 编译（CCS + TivaWare）

1. 新建 CCS 工程，器件选 `TM4C123GH6PM`，引入 TivaWare `driverlib`。
2. 加入源文件：本目录 `wheel.c`、`board_tm4c123g.c`、`main.c`，
   以及 `../library/src/` 下的 `clib_common.c`、`clib_port.c`、`clib_motor.c`（本例程只用这三个）。
   **不要**把 `main.c` / `board_tm4c123g.c` 加进 PC 端 Makefile 编译。
3. Include 路径：本目录、`../library/include`、TivaWare 根目录（要能找到 `inc/...`、`driverlib/...`）。
4. 预定义宏加 `PART_TM4C123GH6PM`（部分版本 `pin_map.h` 需要）。
5. 链接 `driverlib.lib`。若 `IntRegister(FAULT_SYSTICK, ...)` 相关符号报错，
   可改成在 `startup_ccs.c` 里把 SysTick 向量填成 `systick_isr` 并去掉那行注册。
6. 下载后打开板载 ICDI 虚拟串口（115200 8N1），能看到每一步动作名。

## 5. API

| 函数 | 含义 |
|---|---|
| `int Wheel_Init(const clib_port_t *port)` | 注册 port 并让电机保持停止。TM4C 传 `&g_board_port` |
| `int Wheel_Set(int16_t left, int16_t right)` | `−100~100`，正=前进、负=后退、0=滑行，自动钳位。**持续输出，不会自动停车** |
| `int Wheel_Stop(void)` | 四路 0%，滑行停车 |
| `int Wheel_Brake(void)` | 四路 100%，L298N 动态刹车 |

`Wheel_Set(60,60)` 前进、`(0,60)` 左转、`(60,0)` 右转、`(-60,60)` 原地左转、`(60,-60)` 原地右转。

## 6. 上电验收顺序

1. **不接电机**，量 PB6/PB7/PB4/PB5：应为 20kHz PWM，上电瞬间四路全 0%，随动作变化。
2. 接**一个**电机（架空）跑演示，确认 `OUT1/2` 对应左轮、方向正确。
   方向反了：对调该电机两根线，或把 `board_tm4c123g.c` 里 `s_pwm_out[]` 的 0/1 互换。
3. 两个电机一起接，看会不会一加速就掉压重启 → 是则走方案 B。
4. 之后接编码器/超声波时，把 `Wheel_Set()` 放进定时控制环，**不要加 `Delay_ms`**。

## 7. 已知限制

- `board_servo_set_pulse` 是**空实现**（本例程不接舵机）。50Hz 舵机与 20kHz 电机**不能**共用
  `PWMDIV_1`：TM4C 的 PWM 周期寄存器只有 16 位，80MHz 下最长周期 819us ≈ 1.2kHz，
  做不出 20ms。以后做超声波云台请用 Wide Timer 或软件 PWM；若全局改 `PWMDIV_64`，
  电机 20kHz 只剩约 62 个计数，占空比分辨率会掉到 ~1.6%。
- UART 发送用阻塞 `UARTCharPut`，只够调试打印；正式导航控制环必须换中断 + 环形缓冲。
- 本程序是**开环速度指令**。没有编码器就没有 `(x, y, θ)` 位姿反馈，点对点导航还差
  QEI0/QEI1 编码器 + 里程计 + 栅格地图 + 路径规划，见项目长期笔记。
