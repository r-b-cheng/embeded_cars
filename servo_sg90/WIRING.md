# SG90 接线、供电与中位安装

适用板：**EK-TM4C123GXL / TM4C123GH6PM**。旧小车照片中的 STM32 扩展板不能按接口位置直接套用到这块 LaunchPad。实验期间让 L298N 车轮驱动断电，只测试舵机。

## 四根连接逐一对应

先断开 USB、电池/适配器和舵机电源，再接线。沿着 SG90 外壳找它原装的三芯插头；HC-SR04 的 `VCC/Trig/Echo/GND` 四芯插头属于超声波，不能当成舵机接口。

| 导线 | 一端 | 另一端 |
| --- | --- | --- |
| 舵机正极 | SG90 红线，通常在三芯插头中间 | 降压模块固定输出区，经万用表确认的 **+5V** 针 |
| 舵机负极 | SG90 棕/黑线 | 降压模块同一输出区的 **GND** 针 |
| 控制信号 | SG90 橙/黄线 | LaunchPad **PC7 / J4 第 7 脚** |
| 单独共地线 | 降压模块 **GND** 的另一个空针 | LaunchPad **GND / J2 第 1 脚**；也可用 J3 第 2 脚 |

```text
外部电池/适配器 ── 降压模块
                      +5V ─────────── SG90 红线
                      GND ────┬────── SG90 棕/黑线
                              └────── LaunchPad GND（J2.1）
电脑 DEBUG USB ──────────────── LaunchPad
                     PC7（J4.7）────── SG90 橙/黄线
```

本方案中，降压模块到 LaunchPad 的直接连接只有 **GND 共地**。外部 5V 只到舵机红线，不接开发板 `VBUS/5V`、`3.3V` 或任何 GPIO。舵机不接 L298N 电机输出端。

## 开发板针脚怎么找

**正面（芯片和按键朝向你），DEBUG USB 在上方、SW1/SW2 在下方：**

| 信号 | 位置 |
| --- | --- |
| PC7 / J4.7 | 右侧双排针，靠芯片的内列，从上往下第 7 个；位于 PC6 与 PD6 之间 |
| GND / J2.1 | 右侧双排针，靠板边的外列，最上面第 1 个 |

**背面（能看到 `VBUS/+3.3V` 丝印的面），DEBUG USB 同样在上方：**左右会镜像。PC7 位于左侧双排插座的内列第 7 个；GND/J2.1 位于左侧外列最上面。最终以针脚旁的 `PC7`、`GND` 丝印为准，不凭图片中的左右位置猜。

白色舵机/超声波转接板的 `P2.7` 不是 LaunchPad 的引脚名；单舵机实验用杜邦线直接转接 SG90 插头，绕过该转接板的舵机排针。

## 降压模块输出如何确认

本次黑色多路降压模块有固定 5V、3.3V 和可调输出区。中间输出区印有“5V电压”；红色螺丝端子是另一类端子，不能仅因颜色相同就当成固定 5V 排针。黄色可调区、蓝色 3.3V 区不用于这次 SG90 供电。

**排针颜色、内排/外排位置只能帮助找区域，不能代替实物丝印和测量。**先让降压模块单独工作，开发板和舵机均断开：

1. 万用表黑线插 COM，红线插 VΩ，选直流电压档，量程大于预期输入电压；不要插电流档插孔。
2. 黑表笔接模块标注 GND/地符号的针，红表笔接标注 5V 的针。确认极性正确、输出约为正 5V。
3. 关闭模块电源，再接上表中的四根线。不要带电移动插头或调整可调输出。

SG90 原厂标称工作电压为 4.8V；本次用稳定的约 5V 外部电源，单舵机留约 1A 或更多供电余量。余量不表示舵机始终消耗 1A，也不能解决机构卡死。模块额定电流、接线接触和实际负载下的电压仍需确认。

## 上电与断电顺序

1. **双方断电接线**，确认 GND 共地、红线到模块 5V、信号到 PC7，开发板不接外部 5V。
2. 先把 DEBUG USB 完全插稳，`POWER SELECT` 选 Debug，确认开发板独立电源灯正常。不要让舵机先通电再半插、晃动 USB。
3. 再打开舵机 5V，按需要下发保持或两轮试摆命令。保持版本复位后默认不输出脉冲。
4. 结束时先关闭舵机 5V，再断开开发板 USB。要改接线时双方都应断电。

3.3V 控制信号在本次组合中已经能驱动 SG90，不代表所有同名舵机都一样。若换舵机后不识别，应先检查共地、5V 和正确的 PC7 脉冲，再评估合适的单向电平转换，不向 PC7 直接输入 5V。

## 1500µs 中位与车头正前方

1500µs 是控制信号中位，不会自动识别车头方向。SG90 没有通过这三根线返回角度或自动记录零点的功能。先前安装时中位曾明显朝右，增加脉宽到 2100–2200µs 后变化很小，不能靠持续加大脉宽代替调整安装方向。

需要调整时，先用保持命令使舵机到 1500µs，确认停止扫动；随后停止脉冲、关闭电源，再松开舵臂中心固定螺丝，拔起舵臂后换方向装回，使探头朝前。不要带电硬扭输出轴或强行顶住机械限位。若支架不能这样调整，应先检查结构，不能强掰齿轮。

重新上电后从较小试摆开始，再逐步增加幅度。本次重新调整安装方向后，依次试过 1400–1600、1300–1700、1200–1800，最终接受 **1100–1900µs**。左右的实际角度尚未精确标定，安装结构可能导致两侧不对称。

## 本次故障板与正常板的区别

初次实验的一块板出现电源灯灭、上部明显发热；后来更换的另一块板工作正常，并用于当前保持程序和试摆验证。两块板通过不同的 USB 调试器序列号区分，脚本要求填写目标正常板的序列号，防止误操作另一块板。

故障板完全断电后，用户报告 `3.3V—GND≈0.5Ω`、表笔短接约 `0.05Ω`、`VBUS—GND≈160Ω`。这强烈提示 3.3V 轨低阻异常，但没有确认具体损坏元件或事故原因，也不能凭 VBUS 的读数认定该部分完好。背面热区大致对应上部调试区，尚未用限流电源等方法定位。

该故障板应保持断电。后续可由实验室人员在断电状态下，通过原厂 VDD 跳帽初步隔离主控供电支路，再检查公共 3.3V 轨、稳压器、调试芯片及电容。不要直接上电摸热点、向电源轨注入电压、短接跳线或把某颗芯片直接判为损坏。
